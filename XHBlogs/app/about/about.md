## 在做什么

在实验室与编辑器之间来回切换。主要方向是**计算化学与机器学习的交叉**：

- **图神经网络** — 分子性质预测、表征学习，以及怎么把化学先验塞进图结构里。
- **分子对接与虚拟筛选** — 从百万级化合物库中找出值得做实验的那几十个。
- **分子动力学模拟** — 用 GROMACS 观察生物大分子在原子尺度上的动态行为与构象变化。

## 在写什么

- **写代码** — TypeScript 与 Python 是日常，Spring Boot 与 React 是能干活的程度。
- **写工具** — 把重复的科研流程脚本化，把脚本产品化。这个博客本身就是其中之一。

## 一些偏好

- 比起"最新"，更在意"能复现"。
- 比起结论，更在意结论是怎么被验证出来的。
- 相信**负样本比正样本更稀缺**，失败记录比成功记录更有信息量。
